# virtual-consulting-project
A practice repository used to test how GitHub supports virtual consulting work. independent of time and location.
My hypothetical scenario to prove its use is one where i advise a small retail business on adopting AI tools for customer service.
The purpose of this is to explore using GitHub as a shared workspace for a consulting engagement
I will organise this work by using issues for tasks, progress is shown on the project board, and updates are posted in Discussions so anyone in any time zone can follow along.
Created as part of coursework for my university module.
